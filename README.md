# My Documents

Ghi chú, ảnh và liên kết — host trên GitHub Pages.

**Site:** https://baokhoa-code.github.io/my-documents/

Tin, ảnh, link lưu trên máy. Muốn lưu vào repo thì mở site, bấm icon mây, dán token (Contents: Read and write) — dữ liệu vào thư mục `hub/`.

Repo này **public** nên đừng sync ghi chú riêng tư vào đây. Tạo repo private riêng rồi dán `username/repo-private` trong app nếu cần.
